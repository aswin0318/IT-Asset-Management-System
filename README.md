# IT Asset Management System

An IT Asset Management System built to manage organizational IT assets, employees, and asset assignments using a REST-based backend and a simple web interface.

This project is developed as part of an academic mini-project and focuses on clean setup, modular design, and ease of use.

---

## Features

- Add and manage IT assets
- Add and manage employees
- Assign assets to employees
- View asset and assignment details
- Generate basic reports (planned)
- REST API with automatic documentation
- Web-based user interface
